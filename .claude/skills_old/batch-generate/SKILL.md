\# バッチ生成スキル（10本単位）



\## 鉄則

絶対に1本ずつ生成しない。必ず10本まとめて1回のAPI呼び出しで生成する。



\## 手順



\### Step 1: 未生成の映画を10本選ぶ

review\_generated: false のものを10本リストアップする。



\### Step 2: 10本分を1つのプロンプトにまとめて生成



以下の形式で1回のAPI呼び出しで10本分を生成する：



以下10本の映画について、それぞれJSON形式でレビューを生成してください。

各映画の出力形式：

{

&#x20; "slug": "...",

&#x20; "catchphrase": "（1行 感覚的なキャッチフレーズ）",

&#x20; "review": "（200〜300文字 主観的レビュー、音楽への言及必須）",

&#x20; "sound\_description": "（200文字 音楽・音の解説）",

&#x20; "seo\_title": "（32文字以内）",

&#x20; "seo\_description": "（100文字以内）"

}

全体の出力: {"results": \[...10件の配列...]}



\### Step 3: 生成結果をJSONファイルに保存

movies/data/ の各ファイルにマージする。



\### Step 4: review\_generated を true に更新



\## コスト

1バッチ（10本）あたり約$0.01

3,000本全体で約$3
