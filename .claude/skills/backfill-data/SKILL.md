# データ埋め戻しスキル(10件単位・事実確認つき)

**CLAUDE.mdの作業フローを厳守。作曲家名・主題歌は事実データであり、間違いはサイトの信頼性とAI引用可能性を直接損なう。AIの記憶だけで記入することを禁止する。**

## マスター初期化(初回のみ)

`data/masters/` が存在しない場合、以下を実行する:

1. movies.json 全件をスキャンし、既存の composer / genre 等の値を収集
2. 表記ゆれ候補(例:「久石譲」「久石 譲」「Joe Hisaishi」)をグループ化して提示
3. ユーザー承認後、以下の形式でマスターを作成:

```json
// data/masters/composers.json (artists.jsonも同形式)
{
  "entries": [
    {
      "name": "久石譲",
      "name_en": "Joe Hisaishi",
      "slug": "joe-hisaishi",
      "aliases": ["久石 譲"]
    }
  ]
}
```

```json
// data/masters/genres.json — 固定リスト。勝手に追加しない
{
  "genres": ["アクション", "SF", "ドラマ", "コメディ", "ホラー",
    "スリラー", "サスペンス", "ミステリー", "ロマンス", "アニメ",
    "ファンタジー", "アドベンチャー", "戦争", "犯罪", "ミュージカル",
    "音楽映画", "ドキュメンタリー", "時代劇・歴史", "ファミリー",
    "スポーツ", "伝記・実話", "青春"]
}
```

初期リストは提案であり、ユーザーの承認・修正を経て確定する。

## 埋め戻しの優先順位

1. **公開済みページ(slug付きエントリー、現在約811件以上)を最優先**
2. 次に未公開・未生成分
3. `episode` フィールドがあるエントリー(TVシリーズ各話)は**除外**。スキップしてログに残す
4. Type B / Type C は対象外(個別承認がある場合のみ)

## 埋め戻し手順(10件1バッチ)

### Step 1: 対象抽出
composer / artists / genre / director のいずれかが空のエントリーを10件抽出し、リストを提示して承認を得る。

### Step 2: Web検索で事実確認
各映画について検索し、以下を確認する:
- 監督名
- 作曲家(劇伴担当)
- 主題歌・挿入歌のアーティストと曲名
- ジャンル(genres.jsonの固定リストから選択)

**ルール**:
- 確認できた情報のみ記入。確認できなければ `null` のまま残し、`"backfill_note": "unverified"` を付けてログに残す
- 主題歌が存在しない映画は artists を空配列にする(nullとの区別)
- 情報源が食い違う場合は両論を提示してユーザーに判断を仰ぐ

### Step 3: マスター照合
- 新しい作曲家・アーティスト名はマスター追加を提案(slug案も同時に)
- 記入する表記は必ずマスターの `name` を使う

### Step 4: 書き込み形式

```json
"director": "クリストファー・ノーラン",
"genre": ["SF", "アクション"],
"music": {
  "composer": ["ハンス・ジマー"],
  "artists": [
    {"name": "Lady Gaga", "song": "Shallow", "role": "主題歌"}
  ]
}
```

既存フィールド構造との整合はStep 0の構造確認で決定し、**movies.jsonの構造変更は必ず事前承認を得る**。

### Step 5: 検証・サンプル・コミット
- 10件分の記入結果を表形式で提示し、承認を得てからコミット
- コミットメッセージ例: 「データ埋め戻し10件(作曲家・アーティスト・ジャンル)」

## 進捗報告

毎バッチ終了時に必ず報告: 「埋め戻し済み ◯件 / 残り ◯件(全2,750件中)」
