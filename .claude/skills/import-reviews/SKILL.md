# レビューインポートスキル(Google Forms CSV → movies.json)

**CLAUDE.mdの作業フローを厳守。既存エントリーの上書きは絶対禁止。ユーザーが書いたレビュー本文は一字も変更しない。**

## Step 0: 構造確認とCSV特定

1. movies.json の現在の件数と最大の n 値を確認  
2. data/masters/ の3マスターを読み込む  
3. CSVファイルの場所をユーザーに確認(例: Downloads フォルダの「(回答)」CSV)  
4. CSVの列構成を表示して、想定と一致するか確認する

想定する列(Google Forms回答シート): タイムスタンプ / 映画タイトル / 公開年 / レビュー本文 / 監督 / 作曲家(劇伴) / 主題歌・挿入歌 / ジャンル / 備考

## Step 1: パースと正規化

- タイトル前後の空白除去  
- 公開年は4桁数値のみ許容(不正値は空扱いにしてログ)  
- ジャンルはカンマ区切りを配列化  
- 主題歌欄は「アーティスト名 / 曲名」形式を分解(形式外はそのまま保持してログ)  
- **インポート済み管理**: 過去に取り込んだ行を再取り込みしないよう、処理済みのタイムスタンプを `data/import-log.json` に記録し、毎回照合する

## Step 2: 重複チェック(必須)

各行について movies.json 全件と突合する:

1. **タイトル完全一致**(t フィールド、空白・全半角を正規化して比較)  
2. **タイトル類似**(部分一致・表記ゆれ疑い)+ 公開年が近い場合

一致・類似が見つかった行は自動追加せず、「重複疑いリスト」として提示してユーザーの判断を仰ぐ(スキップ / 別作品として追加 / 既存を更新)。

## Step 3: マスター照合

- 作曲家・アーティスト名をマスターと照合。表記ゆれはマスター表記に統一を提案  
- 新規の名前はマスター追加案(slug付き)を提示し、承認後に追加  
- ジャンルは genres.json のリスト外の値を検出したら報告(勝手に追加しない)

## Step 4: プレビューと承認

追加予定エントリーを表形式で提示: | タイトル | 年 | 監督 | 作曲家 | 主題歌 | ジャンル | レビュー冒頭30字 |

あわせて報告する:

- 追加 ◯件 / 重複疑い ◯件 / エラー行 ◯件  
- マスター新規追加 ◯件

**ユーザー承認までmovies.jsonには書き込まない。**

## Step 5: 書き込み

- n は既存の最大値から連番で採番  
- レビュー本文は d フィールドへ(原文のまま)  
- 新フィールド(director / genre / music 等)はCLAUDE.mdの対応表に従う  
- slug は付けない(未公開状態。ページ生成は batch-generate で別途実行)  
- 処理済みタイムスタンプを data/import-log.json に記録

## Step 6: コミット(承認後のみ)

コミットメッセージ例: 「フォームレビュー◯件インポート」。push は報告後。

## 運用メモ

- 推奨頻度: 週1回程度まとめて  
- インポート後の流れ: batch-generate でページ生成 → hub-generate でハブ更新  
- Bearノートからの一括移行にもこのスキルの重複チェックロジックを流用できる(その場合はCSVでなくテキスト形式なので、パース部分だけ個別対応)
