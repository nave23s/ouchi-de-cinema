# ハブページ生成スキル(作曲家・アーティスト・ジャンル)

**CLAUDE.mdの作業フローを厳守。ハブページは movies.json + マスターファイルから全自動生成する。手動編集はしない(再生成で消えるため)。**

## Step 0: 構造確認(毎回必須)

1. `data/masters/` の3マスターが存在するか(なければ backfill-data の初期化を先に)
2. movies.json のフィールド構造を確認
3. ハブ出力先(`/composers/` `/artists/` `/genres/` を想定)を確認。初回はユーザーと合意する

## 生成ルール

### 最低件数ルール(薄いページ防止)
- **該当レビューが3本未満の作曲家・アーティストはハブページを作らない**
- 3本に達したら自動的に生成対象になる
- ジャンルは固定リストなので全件生成してよい

### URL設計
- `/composers/[slug]/` `/artists/[slug]/` `/genres/[slug]/`
- slugはマスターファイルの値を使用
- 各カテゴリのインデックスページ(`/composers/` 等)も生成する

## ハブページの必須構造(AIO対応)

各ハブページには以下を必ず含める:

1. **冒頭定義文(300字以内)** — 断言形式で書く。
   例:「ハンス・ジマーは『インセプション』『ダークナイト』などで知られる映画音楽作曲家です。オウチ de CINEMAでは、ジマーが音楽を手がけた作品◯本を、音・音響の視点からレビューしています。」
2. **作品一覧** — 各作品のキャッチフレーズ+レビューへのリンク(公開年順)
3. **FAQセクション(2〜3問)** — 「○○の代表作は?」「○○の音楽の特徴は?」形式。回答は断言形式50〜80字
4. **著者バイライン** — 「舞台経験で培った耳で、映画の音を聴く」+プロフィールページへのリンク
5. **JSON-LD構造化データ** — 作曲家・アーティストは Person + CollectionPage、ジャンルは CollectionPage
6. **OGP / Twitter Card / GA4(G-NQYTVV8D13) / canonical** — 通常ページと同基準

## 実装手順

### Step 1: 生成スクリプトの作成(初回のみ)
`scripts/generate-hubs.js` を作成する。機能:
- movies.json を読み、マスターのslugごとに作品を集計
- 3本未満はスキップ(スキップリストをログ出力)
- テンプレートからHTML生成
- 既存ハブとの差分がないものは再生成しない(`--changed-only`)

### Step 2: ドライラン
`node scripts/generate-hubs.js --dry-run` で生成対象の一覧(新規/更新/スキップ)を提示し、承認を得る。

### Step 3: 生成とサンプル確認
生成後、**作曲家・アーティスト・ジャンル各1ページのサンプル**を提示して確認を受ける。

### Step 4: サイトマップ更新とコミット
- sitemap.xml にハブページを追加(seo-fixスキルのサイトマップ生成と整合させる)
- レビューページ側にも「この作曲家の他の作品」等の逆リンクを追加する(内部リンク強化。別承認で実施)
- コミットメッセージ例: 「ハブページ生成: 作曲家◯件・アーティスト◯件・ジャンル◯件」

## 運用ルール

- batch-generate / backfill-data の実行後は、このスキルでハブを再生成する(データとハブの不整合を防ぐ)
- マスターに変更があった場合(表記統一・slug変更)は全ハブ再生成+旧URLのリダイレクト要否をユーザーに確認
