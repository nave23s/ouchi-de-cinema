# analytics-report スキル — サイト分析レポート

**完全読み取り専用。movies.json・HTMLファイル・その他サイトファイルへの書き込みは絶対禁止。出力はチャット上のテキストレポートのみ。**

## このスキルの役割

ユーザーがGA4・Search Consoleの画面からコピーしたデータを貼り付けると、以下の5項目のレポートを日本語で作成する。データ分析に基づき、オウチ de CINEMAの編集方針「音の視点から映画を語る」に沿った具体的な次の一手を提案する。

## データ受け取り方式（手動貼り付け型）

APIは使わない。ユーザーが以下のいずれかをチャットに貼り付けることでレポートを生成する。

### 受け取れるデータの種類

| データ | 取得元 | 含む情報の例 |
|--------|--------|------------|
| ページ別PV | GA4「ページとスクリーン」 | ページパス、表示回数、ユーザー数、平均エンゲージメント時間 |
| 流入元内訳 | GA4「トラフィック獲得」 | セッションのデフォルトチャネル、セッション数、コンバージョン |
| 検索クエリ | Search Console「検索結果」 | クエリ、クリック数、表示回数、CTR、掲載順位 |
| 上位ページ | Search Console「ページ」 | URL、クリック数、表示回数、CTR、掲載順位 |

複数データを同時に貼ってもよい。データが部分的でもレポートを作成する（ただし不足分はその旨明記）。

## レポート構成（5項目）

### 1. 人気ページ TOP10（PV順）とその傾向

- PV上位10ページを順位表で表示（URL・PV数・滞在時間）
- 上位に共通するカテゴリ・ジャンル・時代の傾向を読み取る
- 「なぜこのページが伸びているか」を音楽・音の視点を含めて仮説立て

### 2. 流入元の内訳

- オーガニック検索 / SNS / ダイレクト / 参照元 の割合を図示（テキスト棒グラフ）
- 検索流入が多い場合：どのページが牽引しているか
- SNS流入がある場合：どのコンテンツが拡散されているか（データがあれば）

### 3. 検索クエリ分析——どんな言葉で見つけられているか

- クリック数上位クエリを一覧表示
- クエリを「映画タイトル系」「音楽・サントラ系」「視聴方法系」に分類
- 掲載順位が11〜30位（2〜3ページ目）のクエリを「伸びしろ候補」として抽出
- このサイトが狙っていない意外なクエリがあれば注目コメントを付ける

### 4. 編集方針との照合——伸ばすべきページ・作るべき新規レビュー提案3つ

オウチ de CINEMAの差別化軸「音楽・音の視点から映画を語る」と照らし合わせ、以下の観点で提案する。

**提案の型（3案のうちいずれかを組み合わせて出力）**

- **型A：伸び代ページの強化**
  検索表示回数は多いがCTRが低い、または滞在時間が短いページ。Musicセクションの充実・タイトルの見直しで改善の余地あり。

- **型B：上位クエリに対応する新規ページ**
  サントラ・音楽系クエリで検索されているが、対応ページがない。または対応ページはあるが内容が薄い。

- **型C：関連ページ群の強化**
  同じ作曲家・監督・ジャンルで複数クエリがある場合、ハブページ（hub-generateスキル）の作成や内部リンク強化を提案。

各提案には「なぜ今これか」の根拠をデータから引用して明記する。

### 5. 改善アクション（優先順位つき）

以下の形式で3〜5件、平易な日本語で出力する。

```
🔴 今すぐやる（効果大・工数小）
  ・〇〇

🟡 今週中に（効果中・工数中）
  ・〇〇

⚪ 来月までに（効果は中〜長期）
  ・〇〇
```

## 出力時の注意事項

- **数値の断定は避ける**：「〜の可能性があります」「〜が考えられます」など推測を明示
- **データ期間が短い場合（7日未満）**：冒頭に「データ期間が短く、傾向の断定は難しい状況です。参考値としてご覧ください」と必ず明記
- **データが片方のみの場合**：「Search Consoleデータがないため、クエリ分析はスキップします」のように不足を明示
- **個別の数値より傾向を重視**：「このジャンルが強い」「このタイプのタイトルが検索されやすい」という示唆を優先する

## スキル起動時の動作

ユーザーが `/analytics-report` または「分析して」「レポートして」と入力したらこのスキルを起動し、以下のメッセージをそのまま出力する：

---

**analytics-report スキル — 準備完了**

以下のいずれかのデータをこのチャットに貼り付けてください。複数まとめてでもOKです。

**GA4から取れるデータ（管理画面からコピペ）**
- 「レポート → エンゲージメント → ページとスクリーン」の表
- 「レポート → 集客 → トラフィック獲得」の表

**Search Consoleから取れるデータ**
- 「検索パフォーマンス → 検索結果」のクエリ一覧
- 「検索パフォーマンス → 検索結果 → ページ」のURL一覧

表をそのままコピーしてもらえれば読み取ります。期間（直近7日・28日・3ヶ月など）もわかれば一緒に教えてください。
