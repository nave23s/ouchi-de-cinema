# アフィリエイト挿入・管理スキル

**CLAUDE.mdの作業フローを厳守。アフィリエイトIDの変更は禁止。**

## 固定設定(変更禁止)

- Amazon Associates ID: `ouchidecinama-22`(このスペルが正。修正しない)
- リンク形式: `https://www.amazon.co.jp/dp/[ASIN]?tag=ouchidecinama-22`
- 全アフィリエイトリンクに `rel="nofollow sponsored"` を必ず付与(Google規約)

## VOD提携状況の確認(作業前に毎回)

`.claude/affiliate-config.json` で現在の提携状況を確認する（**未存在の場合は初回のみ作成してから作業開始**）。申請中サービス(U-NEXT / Hulu / Disney+ / クランクインビデオ / ABEMA / WOWOW)は承認状況をユーザーに確認してから使う。

- **承認済みのみ**アフィリエイトURLを使用
- 未承認・非提携サービス(Netflix等)は、配信情報として表示する場合も**通常リンクまたはリンクなし**とし、アフィリエイトURLを捏造しない

## 映画データへのアフィリエイト追加手順

### 1. 対象確認
movies.json から対象エントリーを確認。Type C(手書き6ページ)は自動処理対象外。

### 2. VOD配信状況の確認と挿入
配信中サービスを確認し `vod_services`（新規追加フィールド）に追加。配信状況は変動するため、確認日を `vod_checked`（新規追加フィールド、形式 `"YYYY-MM-DD"`）に記録する。これらは movies.json への新フィールド追加であり、既存フィールドの変更ではない。

### 3. Amazonアフィリエイトの追加
ASIN取得の優先順:
1. Blu-ray / 4K版
2. DVD版
3. サウンドトラックCD(音のサイトなので積極的に。作曲家ハブページにも掲載価値あり)
4. 関連書籍・ノベライズ

### 4. 一括チェック
アフィリエイト未設定ページを抽出して件数報告。10件単位で処理し、サンプル確認→承認→コミット。

## 表示のベストプラクティス

1. VODリンクはファーストビューに
2. 無料期間のあるVODを最上位に(「31日間無料で見る」)
3. 表示優先順: 無料期間あり → 月額最安 → 有料レンタル → Blu-ray/DVD → サントラCD
4. Amazon商品は「この映画を気に入ったら」の文脈で自然に
5. 価格は月額を明示
